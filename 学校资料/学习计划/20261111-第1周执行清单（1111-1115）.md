**本周数学基础知识（每天块 3 前读 30 秒）**

- 分式有意义：分母 ≠ 0；分式值为 0：分子 = 0 **且** 分母 ≠ 0
- 分式基本性质：分子分母同乘（除）同一个**不等于 0** 的整式，值不变
- 分式方程必检根：去分母后解出的根要代回**最简公分母**，公分母为 0 的是增根，必须舍
- 因式分解四法顺序：提公因式 → 公式法（平方差 $a^2-b^2=(a+b)(a-b)$、完全平方 $a^2\pm2ab+b^2=(a\pm b)^2$）→ 十字相乘 → 分组分解；**必须分解到每个因式都不能再分解**
- 幂的运算： $a^m \cdot a^n = a^{m+n}$、 $(a^m)^n = a^{mn}$、 $(ab)^n = a^n b^n$、 $a^m \div a^n = a^{m-n}$、 $a^0=1$（ $a \ne 0$）、 $a^{-n}=\dfrac{1}{a^n}$

**本周数学常考点**：分式化简求值（**先化简再代入**，注意题目给的取值不能让分母为 0）；分式方程应用题（设未知数 → 列方程 → 解 → **两步检验**：增根检验 + 实际意义检验）；因式分解与整式乘除的混合运算符号错。
