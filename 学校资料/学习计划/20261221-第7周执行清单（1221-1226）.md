**本周数学基础知识（每天块 3 前读 30 秒）**

- 实数分类：**有理数**（整数 + 分数，含有限小数和无限循环小数）与**无理数**（无限不循环小数，如 $\sqrt2$、 $\pi$、 $0.1010010001\cdots$）
- **绝对值**： $|a|=\begin{cases}a,&a>0\\0,&a=0\\-a,&a<0\end{cases}$； $|a|\ge0$； $|a|=|{-a}|$
- **相反数**： $a$ 与 $-a$，**和为 0**；**倒数**： $a$ 与 $\dfrac1a$（ $a\ne0$），**积为 1**
- **科学记数法** $a\times10^n$，其中 $1\le|a|<10$， $n$ = 整数位数 $-1$（大数）；小于 1 的小数用负指数
- 二次根式： $\sqrt{a}$（ $a\ge0$）； $(\sqrt a)^2=a$（ $a\ge0$）； $\sqrt{a^2}=|a|$； $\sqrt{ab}=\sqrt a\cdot\sqrt b$（ $a,b\ge0$）； $\sqrt{\dfrac ab}=\dfrac{\sqrt a}{\sqrt b}$（ $a\ge0,b>0$）
- **最简二次根式**两个条件：被开方数不含分母、不含能开得尽方的因数或因式；**同类二次根式**才能合并
- 整式运算：合并同类项（系数相加，字母和指数不变）；去括号（括号前是负号，括号内每一项都变号）
- 乘法公式： $(a+b)(a-b)=a^2-b^2$； $(a\pm b)^2=a^2\pm2ab+b^2$

**本周数学常考点（中考综合训练前 10 题的固定套路）**：① 相反数、绝对值、倒数、科学记数法各一题（**送分题，必须全对**）② 二次根式化简与混合运算（**先看能不能化简，再合并同类二次根式**）③ 整式运算与因式分解（**因式分解必须分解到不能再分解**）④ 分式化简求值（**先化简再代入，代入值不能让分母为 0**）⑤ 解方程／不等式组（**不等式乘除负数要变号**）⑥ 几何基础证明（**先走固定四步：标直角 → 标已知角写三边比 → 找可解直角三角形 → 没直角就作垂线**）

  - **标题断句：答／谢中书／书**（**谢中书 = 谢徵（或谢览），「中书」是他的官职**；末字「书」才是「书信」）——这是常考的文学常识坑
  - 记承天寺夜游重点：元丰六年十月十二日夜，解衣欲睡，月色入户，欣然起行、念无与为乐者，遂至承天寺寻张怀民、怀民亦未寝，相与步于中庭、**庭下如积水空明，水中藻荇交横，盖竹柏影也**（xìng）、何夜无月？何处无竹柏？**但少闲人如吾两人者耳**
  - **「闲人」两字是全篇的文眼**：既有赏月的欣喜、漫步的悠闲，也有被贬的悲凉和自我排遣的旷达——**四种情感都要答出来**
- 点拨 5：《点拨》「苏轼常识」——字子瞻，号**东坡居士**，北宋文学家，「唐宋八大家」之一，与父苏洵、弟苏辙合称「三苏」；**本册出现三次**：水调歌头（九上）、记承天寺夜游（八上）、卜算子·黄州定慧院寓居作（八下课外诵读）
- 主项 25：**文言文对比阅读**（课内 + 课外，期末必考题型）。做法：拿《答谢中书书》和《记承天寺夜游》做对比，写三道题的答案：
  - ① 两文都写了「景物」，但写景顺序和手法不同：《答》是**仰视（高峰入云）→ 俯视（清流见底）→ 平视（两岸石壁、青林翠竹）→ 时间顺序（晓雾将歇 / 夕日欲颓）**；《记》只写一处月色，用**比喻（积水空明 = 月光，藻荇 = 竹柏影）**，**正面写月光的空明却不着一个「月」字**
  - ② 两文表达的情感不同：《答》是**沉醉山水的愉悦 + 与古今知音共赏美景的得意**；《记》是**赏月的欣喜 + 漫步的悠闲 + 被贬的悲凉 + 自我排遣的旷达**
  - ③ 两文的共同点：**都用「景 + 情」的结构，都在结尾用一句议论抒情点明心境**

  - 重点字：从小丘西行百二十步，隔**篁竹**，闻水声，如鸣**佩环**，心乐之（huáng）、伐竹取道，下见小潭，水尤**清冽**（liè）、全石以为底，近岸，卷石底以出，为**坻**，为**屿**，为**嵁**，为岩（chí / yǔ / kān）、青树翠蔓，**蒙络摇缀**，参差披拂、潭中鱼可百许头，皆若空游无所依、日光下**澈**，影布石上、**佁然**不动，**俶尔**远逝，往来**翕忽**（yǐ / chù / xī）、似与游者相乐、潭西南而望，**斗折蛇行**，明灭可见、其岸势**犬牙差互**，不可知其源、坐潭上，四面竹树环合，寂寥无人，**凄神寒骨，悄怆幽邃**（qiǎo chuàng）、以其境过**清**，不可久居，乃记之而去
  - **三个必考的词类活用**：**西**行（名词作状语，向西）、**斗**折**蛇**行（名词作状语，像北斗星那样、像蛇那样）、**犬牙**差互（名词作状语，像狗牙那样）、**凄**神**寒**骨（形容词使动用法，使…凄凉、使…寒冷）
  - **写作顺序**：发现小石潭 → 潭中景物（水、石、树、鱼）→ 潭源溪流 → 潭中气氛 → 记录同游者
