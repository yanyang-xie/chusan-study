- 记录日期：2026-11-13
- 起因：海淀期中道法 83 分。客观题 40 分全对，17 分全丢在主观题，丢法一致——**用自己的话抒情，代替用课本的话踩点**。所以缺的不是「认不认识」，是「能不能默写出来」。诊断详见 [2026-初三-海淀-期中-道法-答案解析与错题诊断.md](../期中考试试卷/2026-初三-海淀-期中-道法-答案解析与错题诊断.md)
- 考试形式：**开卷**，只能翻统编教材，90 分钟 30 题。开卷不等于不用背——翻书时间不够，而且翻到的是整段课文，卷面要的是从那段里抽出来的采分词

## 怎么用这份清单

**标记说明**

- ✓ = 本次海淀期中官方评分标准里出现过的原话，属于实证过的采分词，优先背
- 无标记 = 按新版教材目录整理的常考表述，背之前对照课本原文核一遍（我没有教材，见文末「待核对」）
- 「页码」列留空，翻书时自己填。开卷考试翻书速度就是分数，填完这列考场能省很多时间

**过关标准**

- 术语过关 = 盖住清单能默写出词组（不是认得）
- 骨架过关 = 任给一个文体，3 分钟内写出三段各一句
- 时间线过关 = 任给一个表述能说出年份事件，任给年份能说出对应表述

**练法**：别再刷选择题。拿期中卷的官方评分标准反向练——盖住答案先写三条踩点句，再对照评分标准数命中了几个词。命中数上不去就是术语还停在「认识」。

## 二、必背答题骨架

主观题按题型给分，每种题型一个架子。动笔前先默写架子，再往里填材料。

**1. 成就 / 原因类（多点题，如 29 题）**
先把材料里每个事实对着上面的目录找归属，找得到才写。常备五点：党的领导（方向指引）／国有经济·集中力量办大事／创新驱动发展战略／以人民为中心的发展思想／改革开放。
铁律：每个点都必须能从材料里指出一句对应的话，指不出来就换点。期中 29 题跑偏的两点（「市场经济以需求为导向」「社会主义核心价值观」）都是材料里没有依据的。

**2. 推荐词 / 推荐理由（如 26 题）**
这是什么（材料）→ 它见证了什么史实、体现了什么精神（课本）→ 它的意义 → 我们青少年怎么做。

**3. 旁白 / 续写（如 28(2)）**
思想是行动的先导 → 材料里的具体举措（补短板、非遗、公共文化服务）→ 取得的成效（文化获得感、幸福感增强）→ 我们的态度（感受思想伟力，坚定文化自信）。
禁：拿比喻排比当答案。期中这题通篇「思想是武器、是尺子、是方向」，只拿 2/6。**比喻是锦上添花，不是答案本身。**

**4. 变与不变（如 27 题）**
看到「变与不变」立刻画两栏，不许一句话带过。
变 = 时代条件在变（按材料阶段各写一句）+ 人民的具体任务在变 + 生活条件不断改善。
不变 = 坚定的理想信念 + 全心全意为人民服务的根本宗旨 + 不怕困难、艰苦奋斗、无私奉献的精神品质。

**5. 排序理由（如 28(1)）**
要写逻辑词，不要复述各幅图内容：由总到分 / 从问题到成果 / 由历史到现实，末尾加一句「体现了……引领……」。

**6. 时政记事 / 分栏填写（如 30(1)）**
五位一体五个框各写各的，不串门；写完通读一遍专查错别字（期中「能手可及」应为「触手可及」）。

**7. 宣讲稿 / 发言稿（如 30(2)）**
国家各方面取得举世瞩目的成就 → 新时代为青少年成长搭建广阔舞台 → 青少年怎么做（三句固定套路）。
禁：个人抒情随笔；禁：涉及西方、资本等的即兴表述（期中「西方资本口中的被逼」属观点表述不当，倒扣印象分）。

**8. 万能结尾「青少年怎么做」**
树立远大理想、坚定理想信念 / 努力学习科学文化知识 / 增强责任意识（法治意识、创新意识）/ 勇于实践、担当时代责任 / 把个人理想融入国家和民族的发展中 / 为实现中华民族伟大复兴贡献青春力量。
凡是材料讲国家成就、党的事业的主观题，**最后一句默认要落在这里**，写完检查有没有。

## 三、必背史实时间线（不能串位）

| 年份 / 节点 | 事件 | 对应表述（考点） |
|---|---|---|
| 1921 | 中国共产党成立 | 开天辟地的大事变；中国革命的面貌从此焕然一新；开启谋求民族独立、人民解放的奋斗征程；伟大建党精神 |
| 1934—1936 | 长征 | 长征精神（新民主主义革命时期） |
| 1949 | 新中国成立 | **中国人民站起来了**；中国历史进入新纪元 |
| 1956 | 三大改造完成 | 确立社会主义基本制度；进入社会主义革命和建设时期 |
| 1964 / 1970 | 原子弹、氢弹、人造卫星 | "两弹一星"精神（属社会主义革命和建设时期，期中 26 题展品二就是这个） |
| 1960s | 焦裕禄治沙 | 焦裕禄精神（社会主义建设时期） |
| 1978 | 十一届三中全会、改革开放 | **富起来**；决定当代中国命运的关键一招 |
| 2012 | 党的十八大 | 中国特色社会主义进入新时代；**强起来**；社会主要矛盾变化 |
| 2021 | 建党百年 | 全面建成小康社会；脱贫攻坚战取得全面胜利 |
| 2035 | "两步走"第一步 | 基本实现社会主义现代化 |
| 本世纪中叶 | "两步走"第二步 | 建成富强民主文明和谐美丽的社会主义现代化强国 |

高频坑（期中 26(1) 就错在这里）：**建党 ≠ 站起来**。建党对应「面貌焕然一新 / 民族独立人民解放的征程」，站起来是 1949 年新中国成立，富起来是 1978 年改革开放，强起来是新时代。
