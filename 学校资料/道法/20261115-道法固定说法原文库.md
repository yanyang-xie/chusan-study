## 〇、「固定说法」到底指什么

指教材和老师提纲里**成套出现、一字不改**的表述。阅卷按句子里有没有那几个词组给分，不按「意思对不对」给分。本卷三个实例：

- 孩子写「党全心全意为人民」——意思对，但采分词组是「全心全意为人民服务的**根本宗旨**」，少了归属词就踩不实（27 题）。
- 孩子写「共产党人心中的光明」——自创比喻，采分词 0 个（27 题）。
- 孩子写「思想是时代之母，实践为理论之源」——教材原句是「**时代**是思想之母，**实践**是理论之源」，主语写反了。这种错比写不出更亏：背过，但背串了（28(2)）。

所以固定说法有三个特征：**成套**（几个词组绑定出现）、**搭配固定**（「更基础、更广泛、更深厚」不能换成「最基础、最广泛、最深厚」）、**归属固定**（哪句话挂在哪个历史时期、哪个框上，不能挪）。下面按框把句子列全。

## 一、第一单元 坚持党的全面领导（第 1–3 课）

### 第一课 百年大党风华正茂

#### 1.1 书写恢宏史诗

- 【卷·26(1)】中国共产党的诞生，是开天辟地的大事变，中国革命的面貌从此焕然一新，开启了谋求民族独立、人民解放的奋斗征程。
- 【纲·P2】中国共产党的成立，使中国人民的斗争有了主心骨，中国人民的精神由被动转为主动。
- 【纲·P5】百年史诗证明，只有中国共产党才能带领中华民族实现伟大复兴。
- 【卷·26(1)】改革开放极大解放和发展社会生产力，激发社会活力，推动国家经济快速发展，是实现民族复兴的关键一招。（完整搭配：改革开放是决定当代中国命运的关键一招，也是决定实现中华民族伟大复兴的关键一招。）

四个历史时期 × 四个「地」 × 四句「条件 / 基础」（【纲·P5】。26(1) 的史实错位就错在这张表）：

| 时期（起止） | 一个「地」 | 这一时期创造 / 奠定 / 提供了什么 |
|---|---|---|
| 新民主主义革命时期（1919/1921—1949） | 开天辟地 | 创造了根本社会条件 |
| 社会主义革命和建设时期（1949—1978） | 改天换地 | 奠定了根本政治前提和制度基础 |
| 改革开放和社会主义现代化建设新时期（1978—2012） | 翻天覆地 | 提供了充满新的活力的体制保证和快速发展的物质条件 |
| 中国特色社会主义新时代（2012— ） | 惊天动地 | 提供了更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量 |

易错：社会主义制度确立于 **1956 年三大改造完成**，不是 1949 年新中国成立（【纲·P31】判断纠正 1）。

- 【纲·P7】伟大建党精神是中国共产党的精神之源。
- 【纲·P7】（伟大建党精神）让党历经百年而风华正茂，饱经磨难而生生不息。

### 第二课 坚持以人民为中心

#### 2.1 牢记初心使命

- 【纲·P10】中国共产党是中国工人阶级的先锋队，同时是中国人民和中华民族的先锋队，是中国特色社会主义事业的领导核心。（性质）
- 【卷·27】【纲·P10】全心全意为人民服务是党的根本宗旨。
- 【卷·判断2】中国共产党一经诞生，就把为中国人民谋幸福、为中华民族谋复兴确立为自己的初心使命。
- 【纲·P10】党的最高理想和最终目标是实现共产主义。
- 【纲·P10】这个初心使命，是激励一代代中国共产党人前赴后继、英勇奋斗的根本动力；是党的性质宗旨、理想信念、奋斗目标的集中体现。
- 【纲·P10】立党为公、执政为民是党的执政理念。
- 【纲·P10】人民对美好生活的向往就是党的奋斗目标。
- 【纲·P10】党没有自己的特殊利益，始终把人民利益放在第一位，代表最广大人民的根本利益。
- 【卷·29④】坚持以人民为中心的发展思想。

六个「根本 / 最高」不能串（【纲·P10/P31/P32】）：

| 问法 | 唯一答案 |
|---|---|
| 根本宗旨 | 全心全意为人民服务 |
| 初心使命 | 为中国人民谋幸福、为中华民族谋复兴 |
| 根本政治立场 | 人民立场 |
| 执政理念 | 立党为公、执政为民 |
| 发展思想 | 以人民为中心 |
| 最高理想和最终目标 | 实现共产主义 |

说「全心全意为人民服务的执政理念」「党的初心使命是全心全意为人民服务」都判错（【纲·P27】选择④、【纲·P31】纠正 5、【纲·P32】纠正 7）。

#### 2.2 站稳人民立场

- 【纲·P11】人民立场是中国共产党的根本政治立场。
- 【纲·P11】人民是历史的创造者，是决定党和国家前途命运的根本力量。
- 【纲·P11】党始终同人民在一起，为人民利益而奋斗，在任何时候都把人民利益放在第一位。
- 【纲·P11】把人民拥护不拥护、赞成不赞成、高兴不高兴、答应不答应作为衡量工作得失的根本标准。（提纲简称「四个答不答应」，完整措辞待核）
- 【纲·P11】群众路线：一切为了群众，一切依靠群众，从群众中来，到群众中去。
- 【卷·选择15】党始终站稳人民立场，自觉贯彻党的群众路线；「我将无我，不负人民」。

- 【纲·P3】中国共产党是中国特色社会主义事业的坚强领导核心。
- 【卷·判断3】中国共产党的领导是中国特色社会主义最本质的特征。
- 【纲·P3】党的领导是中国特色社会主义制度的最大优势。
- 【纲·P3】党的领导是现代化建设、民族复兴的最根本保证。
- 【纲·P28】中国共产党是最高政治领导力量，根本组织原则是民主集中制。
- 【卷·选择17】在国家治理体系的大棋局中，党中央是坐镇中军帐的「帅」。

- 【卷·26(2)】中国共产党的领导是历史和人民的选择。
- 【纲·P35】两个确立：确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位。
- 【纲·P3/P35】两个维护：坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导。
- 【纲·P32】坚持和加强党的全面领导，最重要的是坚决维护党中央权威和集中统一领导，最关键的是坚决维护习近平同志党中央的核心、全党的核心地位。（「最重要 / 最关键」的宾语互换即判错，纠正 10）
- 【纲·P3】青少年：思想上坚定理想、学习上练就本领、守法上抵制错误言行、生活上志愿服务、组织上向团组织靠拢。
- 【推】党领导立法、保证执法、支持司法、带头守法；党必须在宪法和法律范围内活动。（九上的宪法落点，两份材料均未给原句，翻书核）

## 二、第二单元 进入新时代（第 4–6 课）

### 第四课 新的历史方位

#### 4.1 社会主要矛盾的变化

- 【纲·P38】我国社会主要矛盾已经转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。
  旧表述「物质文化需要同落后的社会生产之间的矛盾」已作废（【卷·判断6】判 ×）。
- 【纲·P38】社会主要矛盾的变化是我国进入新时代的基本依据。
- 【纲·P38】两个不变：我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，我国是世界最大发展中国家的国际地位没有变。
  （【卷·判断7】「经济总量世界第二 = 发达国家」判 ×；【卷·选择18③】「跨越初级阶段」判错）
- 【纲·P38】要牢牢把握社会主义初级阶段这个基本国情，牢牢立足社会主义初级阶段这个最大实际，毫不动摇贯彻党在社会主义初级阶段的基本路线。（基本路线 = 一个中心、两个基本点，【纲·P34】）

#### 4.2 进入新时代的意义

（提纲 P39 的标题作「新时代的内涵与意义」，目录作「进入新时代的意义」，是同一框。）

- 【卷·判断5】党的十八大以来，中国特色社会主义进入新时代。
- 【纲·P34】中国特色社会主义进入新时代，这是我国发展新的历史方位。
- 【纲·P39】三个意味着：①意味着近代以来久经磨难的中华民族迎来了从站起来、富起来到强起来的伟大飞跃；②意味着科学社会主义在 21 世纪的中国焕发出强大生机活力；③意味着拓展了发展中国家走向现代化的途径，为解决人类问题贡献了中国智慧和中国方案。
- 【纲·P39】五个时代（内涵）：①承前启后、继往开来、在新的历史条件下继续夺取中国特色社会主义伟大胜利的时代；②决胜全面建成小康社会、进而全面建设社会主义现代化强国的时代；③全国各族人民团结奋斗、不断创造美好生活、逐步实现全体人民共同富裕的时代；④全体中华儿女勠力同心、奋力实现中华民族伟大复兴中国梦的时代；⑤我国不断为人类作出更大贡献的时代。
- 易错：共同富裕 ≠ 同步富裕 ≠ 同等富裕（【纲·P39】、【卷·选择20乙】）。

### 第五课 新时代的思想旗帜

#### 5.1 系统科学的理论体系

- 【纲·P40】**时代是思想之母，实践是理论之源。**
  ⚠️ 孩子 28(2) 写成「思想是时代之母，实践为理论之源」，主语反了。这句和 5.2 的「思想是行动的先导」是 28(2) 开头最该踩的两句话。
- 【纲·P40】坚持把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合。（两个结合）
- 【纲·P40】主要内容：十个明确、十四个坚持、十三个方面成就。
- 【纲·P40/P44】六个必须坚持：必须坚持人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。
- 【纲·P41–43】四块各自的角色：十个明确 = 「是什么」，理论核心、四梁八柱；十四个坚持 = 「怎么做」，基本方略、实践路径；十三个方面成就 = 「怎么样」，实践成果；六个必须坚持 = 世界观方法论的「金钥匙」。
- 【纲·P45】十个明确、十四个坚持、十三个方面成就、六个必须坚持内在贯通、有机统一，共同构成了习近平新时代中国特色社会主义思想的科学体系。
- 【纲·P42】十四个坚持（提纲分组版）：一个中心——坚持以人民为中心；两个领导——坚持党对一切工作的领导、坚持党对人民军队的绝对领导；三个全面——坚持全面深化改革、坚持全面依法治国、坚持全面从严治党；五位一体——坚持新发展理念、坚持人民当家作主、坚持社会主义核心价值体系、坚持在发展中保障和改善民生、坚持人与自然和谐共生；统一安全共同体——坚持「一国两制」和推进祖国统一、坚持总体国家安全观、坚持推动构建人类命运共同体。
- 【纲·P44】六个必须坚持是根本立场（怎么想，世界观方法论），十四个坚持是实践方略（怎么做，落实政策举措）。「人民至上」和「以人民为中心」分属两块，别混。

- 【卷·28(2)】**思想是行动的先导。**
- 【纲·P46】实践是理论的基础，科学理论对实践又具有巨大指导作用。
- 【纲·P35/P46】习近平新时代中国特色社会主义思想是当代中国马克思主义、二十一世纪马克思主义，是中华文化和中国精神的时代精华，实现了马克思主义中国化时代化新的飞跃。
- 【纲·P36/P46】新时代党和国家事业取得历史性成就，最根本的原因在于有习近平同志作为党中央的核心、全党的核心掌舵领航，在于有习近平新时代中国特色社会主义思想的科学指引。
