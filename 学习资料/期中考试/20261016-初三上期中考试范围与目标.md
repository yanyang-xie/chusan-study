## 一、物理

### 考试范围

以**九年级上册**为主，按目前进度预计覆盖到欧姆定律/特殊方法测电阻一带：

1. **机械能**——动能、势能（重力势能和弹性势能）及其转化，机械能守恒的定性判断
2. **内能**——温度、内能、热量三者关系，改变内能的两种方式（做功和热传递），比热容与热量计算，热机（四冲程、能量转化、效率）
3. **电学初步**——摩擦起电与两种电荷、原子结构；电流和电路、通路/断路/短路；串联与并联的识别与画法；电流表、电压表的读数与使用；变阻器；电阻；欧姆定律（I=U/R）及简单计算；伏安法测电阻与**特殊方法测电阻**（缺电流表 / 缺电压表 / 单表 + 定值电阻 / 等效替代等）
4. **上学期力学复习**（因进度差异需自行补）——力的概念与三要素、重力弹力摩擦力、牛顿第一定律与惯性、二力平衡、压强（固体压强、液体压强、大气压）、浮力（阿基米德原理、物体浮沉条件）、功与功率

### 目标

电学新课（尤其电路故障判断、特殊方法测电阻）不丢分；力学旧内容把上学期的错题捡回来，不因遗忘失分。

## 五、道德与法治

### 考试范围

**所有与中国共产党、宪法、法律以及党史相关的知识点。**

重要背景：**2026 年秋季起九年级道德与法治换用全新教材**（统编版/人教版 2026 新版，依 2022 版课标重编），与旧版结构差别很大。新版九年级上册目录：

| 单元 | 课 | 框 |
|---|---|---|
| 第一单元 坚持党的全面领导 | 第一课 百年大党风华正茂 | 1.1 书写恢宏史诗；1.2 弘扬伟大建党精神 |
| | 第二课 坚持以人民为中心 | 2.1 牢记初心使命；2.2 站稳人民立场 |
| | 第三课 党是领导一切的 | 3.1 坚强的领导核心；3.2 坚持和加强党的全面领导 |
| 第二单元 进入新时代 | 第四课 新的历史方位 | 4.1 社会主要矛盾的变化；4.2 进入新时代的意义 |
| | 第五课 新时代的思想旗帜 | 5.1 系统科学的理论体系；5.2 必须长期坚持的指导思想 |
| | 第六课 中国腾飞谱新篇 | 6.1 经济实力大幅跃升；6.2 民主政治不断发展；6.3 文化自信日益增强；6.4 民生福祉持续增进；6.5 美丽中国加快建设 |
| 第三单元 奋进新征程 | 第七课 擘画宏伟蓝图 | 7.1 "两步走"战略；7.2 中国式现代化 |
| | 第八课 推动高质量发展 | 8.1 贯彻新发展理念；8.2 构建新发展格局 |
| 第四单元 共圆中国梦 | 第九课 凝聚团结伟力 | 9.1 铸牢中华民族共同体意识；9.2 实现祖国完全统一 |
| | 第十课 实现伟大梦想 | 10.1 民族复兴梦；10.2 我们都是追梦人 |

按此目录，用户说的四类知识点落在：

- **中国共产党 / 党史** → 第一单元整单元（百年奋斗四个历史时期、伟大建党精神、初心使命、人民立场、领导核心、党的全面领导），外加第四、五课（新时代、指导思想）
- **宪法、法律** → 九年级上册**没有专门的法治单元**（这是新教材和旧版差别最大的地方之一）。承载点只有 3.2（党领导立法、保证执法、支持司法、带头守法；党必须在宪法和法律范围内活动）和 6.2（民主政治不断发展、全面依法治国）。**成体系的宪法知识在八年级下册**（坚持宪法至上、公民权利义务、国家机构），**法律基础知识在七年级下册和八年级上册**。所以"宪法、法律"这一块到底是只考九上涉及的部分，还是要跨册回看八下，**必须找学校要复习提纲确认**。
- 与时政热点结合出题（2026 年北京中考道法为**开卷**考试、只能翻统编教材，题型含判断题 + 选择题 + 分析说明题；学校期中是否开卷也待确认）。

### 目标

把党/党史核心表述背到能默写（开卷也要能**立刻定位到第几课第几页**）；宪法法律部分先把跨册知识点串成清单。

### 已有资产

**无。** `questions/道德与法治/` 目录尚不存在，仓库里没有任何道法记录（化学同样为空）。这是五科里唯一完全空白的一科。

### 待办（需用户配合）

1. 找学校/老师要期中复习提纲或进度表，确认：截止第几课、是否开卷、宪法法律是否跨册考八下内容。
2. 拿到后按上面范围整理知识点清单，存到 `questions/道德与法治/`（目录待建）。
