## 原文（【】内为本次默写不会写的字）

北国风光，千里冰封，万里雪【飘】。
望长城内外，【惟余莽莽】；
大河上下，【顿失滔滔】。
山舞银蛇，原驰【蜡象】，欲与天公试比高。
须晴日，看红装素【裹】，分外妖娆。

江山如此多娇，引无数英雄竞折腰。
惜秦皇汉武，略输文采；
唐宗宋祖，稍逊风骚。
一代天骄，成吉思汗，只识弯弓射大【雕】。
俱往矣，数风流人物，还看今朝。

## 生字注音与字形拆解

| 字 | 拼音 | 字形记忆与备注 |
| -- | ---- | -------------- |
| 沁 | qìn | 沁园春是**词牌名**。左「氵」右「心」——水浸透心，「沁人心脾」的沁。不要写成「泌」（mì/bì，如分泌） |
| 惟余莽莽 | wéi yú mǎng mǎng | 「惟」左「忄」右「隹」（zhuī，四横），课本用「惟」不写「唯」。「莽莽」= 草（艹）+ 犬 + 廾，二「土」夹「犬」：形容原野苍茫、白茫茫一片 |
| 顿失滔滔 | dùn shī tāo tāo | 「顿」左「屯」右「页」；「滔滔」三点水 + 「舀」（yǎo，上「爪」下「臼」），指黄河失去了滚滚奔腾的水势（天寒冻结） |
| 原驰蜡象 | yuán chí là xiàng | 「驰」马字旁，（马）奔跑，不要写成「驰」的右边「也」少写；「蜡」虫字旁 + 「昔」——白蜡、蜡烛都是蜡，别写成「腊」（月肉旁，腊肉） |
| 裹 | guǒ | 「红装素裹」：衣服裹在身上，中间是「果」，外面是「衤」（衣字分解为亠+果+衣），记住「果在衣中」 |
| 妖娆 | yāo ráo | 「娆」女字旁 + 「尧」（上「戈」无点、下「兀」），形容姿态美好。不要写成「绕」（绞丝旁） |
| 竞 | jìng | 「竞折腰」的「竞」= **竞争**的竞，上「立」下「兄」。与「毕竟」的「竟」（上「音」头下「儿」）区分，见易错提醒 |
| 雕 | diāo | 左边「周」，右三撇「彡」——猛禽羽毛之形。不要写成「凋」（凋零，两点水） |

## 名句与考点

- **北国风光，千里冰封，万里雪飘**：总写北国雪景，「封」写静态之冻，「飘」写动态之雪。
- **望长城内外……顿失滔滔**：一个「望」字领起下文（领字考点）。山、原皆动——化静为动。
- **山舞银蛇，原驰蜡象**：对偶 + 比喻，群山如银蛇飞舞，高原丘陵如白象奔跑。
- **须晴日，看红装素裹，分外妖娆**：想象雪后晴日，红日照耀白雪，娇艳壮美。
- **惜秦皇汉武……只识弯弓射大雕**：评点历代帝王，「略输」「稍逊」分寸极有讲究，含蓄批评只重武功、轻文治。
- **俱往矣，数风流人物，还看今朝**：全词主旨，歌颂当代革命者，气魄雄伟。

## 易错字提醒

- 「**竞**折腰」与「**竞**赛」的「竞」（竞争义，上「立」下「兄」）；不要写成「**竟**」（毕竟、竟然）。这是本词最高频错字，本次连错四次，重点抄写区分：
  - 竞（jìng）＝竞争、竞折腰 → **立 + 兄**
  - 竟（jìng）＝毕竟、究竟 → **音 + 儿**
- 「惟余莽莽」不要写成「唯余茫茫」（课本用「惟」「莽莽」）
- 「原驰蜡象」的「蜡」是虫字旁（蜡烛），不是月肉旁的「腊」
- 「红装素裹」的「裹」中间是「果」，别丢笔
- 「顿失滔滔」两个「滔」都是三点水 + 舀
- 成吉思**汗**读 hán，不读 hàn
