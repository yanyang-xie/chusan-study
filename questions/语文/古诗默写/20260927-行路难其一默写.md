# 行路难（其一）默写

**作者**：李白（唐）

---

金【樽】清酒斗十千，玉盘珍【羞】【直】万钱。

停杯投【箸】不能食，拔剑四【顾】心【茫】然。

欲渡黄河冰【塞】川，将登太行雪满山。

闲来垂钓【碧】溪上，忽复乘舟梦日边。

行路难，行路难，多【歧】路，今安在？

长风破浪会有时，直挂云【帆】【济】沧海。

---

## 生字注音

| 字 | 拼音 | 备注 |
| -- | ---- | ---- |
| 樽 | zūn | 古代盛酒的器具 |
| 羞 | xiū | 同「馐」，美味的食物 |
| 直 | zhí | 此处读 zhí，通「值」，价值；注意与末句「直挂云帆」的「直」（径直）区分 |
| 箸 | zhù | 筷子 |
| 顾 | gù | 看，「四顾」即向四周看 |
| 茫 | máng | 模糊不清，「茫然」指心中迷茫、无所适从；上「艹」下「氵+亡」 |
| 塞 | sè | 阻塞、堵住 |
| 太行 | tài háng | 太行山，「行」读 háng 不读 xíng |
| 碧 | bì | 青绿色，结构：左上「王」、左下「白」、右「石」 |
| 歧 | qí | 岔路，「歧路」即岔道 |
| 帆 | fān | 船帆，左边「巾」旁，不要写成别旁 |
| 济 | jì | 渡、渡过 |

## 名句与考点

- **停杯投箸不能食，拔剑四顾心茫然**：连用「停、投、拔、顾」四个动作，写出内心苦闷抑郁、彷徨无措。
- **欲渡黄河冰塞川，将登太行雪满山**：以路途艰险比喻仕途受阻，用典含蓄（黄河、太行）。
- **闲来垂钓碧溪上，忽复乘舟梦日边**：借姜尚（吕尚）渭水垂钓、伊尹梦乘舟过日月的典故，表达对重新被任用仍存希望。
- **长风破浪会有时，直挂云帆济沧海**：借用宗悫「愿乘长风破万里浪」的典故，是全诗最强音——坚信理想终能实现，抒发豪迈乐观之情。

## 情感脉络

苦闷（停杯投箸）→ 彷徨（四顾茫然）→ 受阻（冰塞川、雪满山）→ 希望（垂钓碧溪、梦日边）→ 迷茫（多歧路，今安在）→ 自信豪迈（长风破浪、云帆济海）。

感情在「失望—希望」之间反复起伏，最终以昂扬乐观收束，这是本诗最重要的特点。

## 易错字提醒

- 「樽」不要写成「尊」；「箸」不要写成「著」
- 「珍羞」的「羞」通「馐」，默写按课本原文写「羞」
- 「歧路」的「歧」不要写成「岐」（岐山的岐）
- 「济沧海」的「济」不要写成「挤」或「剂」
- 「碧」字结构易错：左上「王」、左下「白」（王白上下排）、右「石」，三部分位置不要摆错
- 「帆」左边是「巾」旁（与布帛有关），不要写成别的偏旁；书写时注意右旁笔画完整，易丢笔
