## 原文（【】内为本次默写不会写的字）

明月几时有？把酒问青天。不知天上宫【阙】，今夕是何年。我欲乘风归去，又恐琼楼玉宇，高处不胜寒。起舞弄清影，何似在人间。

转朱【阁】，低【绮】户，照无【眠】。不应有恨，何事长向别时圆？人有悲欢离合，月有阴晴圆缺，此事古难全。但愿人长久，千里共【婵娟】。

## 生字注音与字形拆解

| 字 | 拼音 | 字形记忆与备注 |
| -- | ---- | -------------- |
| 阙 | què | 「宫阙」= 宫殿。门字框「门」里一个「欮」（上「木」下「欠」类结构，右上「夬」）。和「十口之家」的「阅」（门+兑）区别：里面不同。难点字，多抄几遍 |
| 琼楼玉宇 | qióng lóu yù yǔ | 「琼」王字旁 + 「京」——美玉做的楼；「宇」宝盖头 + 「于」——天空、宇宙 |
| 不胜寒 | bù shèng hán | 「胜」读 shēng 时是「承受」义（高处不胜寒＝受不住高处的寒冷），写法不变，注意读音 |
| 阁 | gé | 门字框 + 「各」——朱阁 = 红色楼阁。与「阙」（门+欮）、「阁」（门+各）对照，别互换 |
| 绮 | qǐ | 绞丝旁 + 「奇」——有花纹的丝织品，「绮户」即雕花门窗。读 qǐ **不读 yǐ**（与「旖旎」的「旖」区分） |
| 眠 | mián | 目字旁 + 「民」——眼睛闭住入睡。别写成日字旁 |
| 婵娟 | chán juān | 都是女字旁：「婵」边「单」，「娟」边「肙」（上「口」下「月」）。本词中借指月亮，引申指美好的样子 |

## 名句与考点

- **明月几时有？把酒问青天**：开篇直问青天，气势浪漫，化用李白「青天有月来几时，我今停杯一问之」。
- **我欲乘风归去，又恐琼楼玉宇，高处不胜寒**：天上与人间之间的矛盾——既向往超脱，又眷恋人世。
- **起舞弄清影，何似在人间**：由天上回到人间，领悟到人间生活值得热爱。
- **转朱阁，低绮户，照无眠**：写月的移动（转过朱红的楼阁，低低照进雕花门窗），也写夜已深、人难眠。
- **人有悲欢离合，月有阴晴圆缺，此事古难全**：由怨月到悟理——自古完美难得，体现旷达胸襟。
- **但愿人长久，千里共婵娟**：全词最强音。遥祝远方的亲人（弟弟子由），即使相隔千里，也能共赏同一轮明月。常考句。

## 情感脉络

望月（问青天）→ 问月（欲归又恐）→ 怨月（何事长向别时圆）→ 悟理（此事古难全）→ 祝愿（千里共婵娟）。

由个人的骨肉分离，升华为对天下离人的美好祝愿，表现苏轼**旷达乐观**的胸襟。

## 易错字提醒

- 「宫**阙**」不要写成「宫阅」或「宫越」；门里是「欮」不是「兑」
- 「转朱**阁**」不要写成「阙」——阁（门+各）是楼阁，阙（门+欮）是宫殿门前的高台，两者都从门，里面部件不同
- 「低**绮**户」的「绮」读 qǐ 不读 yǐ，别写成「奇」（丢绞丝旁）
- 「照无**眠**」的「眠」是目字旁，不要写成「眼」或日字旁
- 「**婵娟**」都是女字旁，不要写成「蝉娟」（虫字旁是蝉）
- 「高处不胜寒」的「胜」读 shēng，义为「承受」，默写字不变
