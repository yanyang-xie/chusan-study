# 《曹刿论战》讲解

选自《左传·庄公十年》，记的是齐鲁长勺之战（鲁庄公十年＝公元前 684 年）。2026 秋新教材把原九年级下册第六单元整体前移，本课现在是**九年级上册第六单元第 23 课**（教读），同单元还有《邹忌讽齐王纳谏》《陈涉世家》《出师表》。全文只有二百余字，却把「战前为什么能打、战中什么时候打、战后为什么赢」三层讲全了——题目叫「论战」，不叫「长勺之战」，原因就在第五节。

## 一、原文与逐句对译

### 第一段：战前论「凭什么打」

> 十年春，齐师伐我。公将战。曹刿请见。其乡人曰：「肉食者谋之，又何间焉？」刿曰：「肉食者鄙，未能远谋。」乃入见。问：「何以战？」公曰：「衣食所安，弗敢专也，必以分人。」对曰：「小惠未徧，民弗从也。」公曰：「牺牲玉帛，弗敢加也，必以信。」对曰：「小信未孚，神弗福也。」公曰：「小大之狱，虽不能察，必以情。」对曰：「忠之属也。可以一战。战则请从。」

**关于「徧」字**：「徧」同「遍」，遍及、普遍。这个字不同印本写法不一——旧部编本印「徧」，不少新印本和教辅印「遍」。**默写以孩子手上那本课本第 23 课的字形为准，请翻书核对一次**；考通假字时答「徧同遍，遍及、普遍」。

逐句对译（加粗的是翻译采分字词）：

- 十年春，齐师伐我。——鲁庄公十年的春天，齐国军队攻打**我们鲁国**。（「十年」是鲁庄公十年，不是「十年以后」；「我」指鲁国，《左传》站在鲁国立场记事。）
- 公将战。曹刿请见。——鲁庄公将要迎战。曹刿请求（庄公）接见。
- 其乡人曰：「肉食者谋之，又何间焉？」——他的同乡说：「当权的人自会谋划这件事，你又何必**参与**呢？」（肉食者＝吃肉的人，指当权者；间 jiàn＝参与；焉＝语气词，呢。）
- 刿曰：「肉食者鄙，未能远谋。」——曹刿说：「当权的人**目光短浅**，不能深谋远虑。」
- 乃入见。问：「何以战？」——于是进宫拜见。（曹刿）问：「（您）**凭借**什么作战？」（何以战＝以何战，宾语前置。）
- 公曰：「衣食所安，弗敢专也，必以分人。」——庄公说：「衣食这类用来**安身**的东西，不敢**独自享有**，一定把（它）分给别人。」
- 对曰：「小惠未徧，民弗从也。」——（曹刿）回答说：「这种小恩小惠不能**遍及**百姓，老百姓是不会**听从**您的。」
- 公曰：「牺牲玉帛，弗敢加也，必以信。」——庄公说：「**祭祀用的牲畜**、玉器和丝织品，不敢**虚夸**数目，一定按照**实情**（报告神灵）。」
- 对曰：「小信未孚，神弗福也。」——（曹刿）回答说：「（这只是）小信用，未能**使神灵信服**，神是不会**保佑**您的。」（福＝赐福、保佑，名词作动词。）
- 公曰：「小大之狱，虽不能察，必以情。」——庄公说：「大大小小的**诉讼事件**，**即使**不能件件**明察**，也一定根据**实情**（处理）。」
- 对曰：「忠之属也。可以一战。战则请从。」——（曹刿）回答说：「（这）是**尽了职分**一**类**的事情，**可以凭借**（这个条件）打一仗。如果作战，请允许（我）跟随（您去）。」

### 第二段：战中指挥「什么时候打」

> 公与之乘，战于长勺。公将鼓之。刿曰：「未可。」齐人三鼓。刿曰：「可矣。」齐师败绩。公将驰之。刿曰：「未可。」下视其辙，登轼而望之，曰：「可矣。」遂逐齐师。

- 公与之乘，战于长勺。——庄公和他（曹刿）同坐一辆战车，在长勺（鲁国地名，今山东莱芜东北）作战。（乘 chéng；战于长勺＝于长勺战，状语后置。）
- 公将鼓之。刿曰：「未可。」——庄公将要**击鼓进军**。曹刿说：「还不行。」（鼓＝击鼓进军，名词作动词；之＝音节助词，不译。）
- 齐人三鼓。刿曰：「可矣。」——齐军击了三次鼓。曹刿说：「可以了。」
- 齐师败绩。——齐军大败。（败绩＝军队溃败。）
- 公将驰之。刿曰：「未可。」——庄公将要**驱车追赶**。曹刿说：「还不行。」
- 下视其辙，登轼而望之，曰：「可矣。」——（曹刿）**下车**察看齐军的**车辙**，又**登上车前的横木**远望齐军，说：「可以了。」（辙 zhé＝车轮碾出的痕迹；轼 shì＝车厢前做扶手的横木。）
- 遂逐齐师。——于是**追击**齐军。（遂＝于是、就；逐＝追击。）

### 第三段：战后论「为什么赢」

> 既克，公问其故。对曰：「夫战，勇气也。一鼓作气，再而衰，三而竭。彼竭我盈，故克之。夫大国，难测也，惧有伏焉。吾视其辙乱，望其旗靡，故逐之。」

- 既克，公问其故。——**已经**战胜之后，庄公问（取胜的）**原因**。（既＝已经；克＝战胜；故＝原因。）
- 对曰：「夫战，勇气也。——（曹刿）回答说：「作战，靠的是勇气。（夫 fú，句首发语词，表示要发议论，不译；判断句。）
- 一鼓作气，再而衰，三而竭。——**第一次**击鼓能**振作**士气，**第二次**（击鼓）士气就衰减了，**第三次**（击鼓）士气就耗尽了。（再＝第二次；竭＝穷尽；句中省略了「鼓」「气」。）
- 彼竭我盈，故克之。——**他们的**士气耗尽了，**我们的**士气正**旺盛**，**所以**战胜了他们。」（彼＝他们，指齐军；盈＝充满，指士气旺盛。）
- 夫大国，难测也，惧有伏焉。——齐是大国，难以**推测**（它的实情），怕**在那里**有埋伏。（测＝推测、估计；焉＝兼词，于此、在那里。）
- 吾视其辙乱，望其旗靡，故逐之。——我看到他们的车辙乱了，望见他们的旗子**倒下**了，所以追击他们。」（靡 mǐ＝倒下。）

## 三、字词过关

### 3.1 通假字

- 小惠未**徧**：徧同「遍」，遍及、普遍。

### 3.2 古今异义（用今天的意思去套就全错）

| 词 | 古义 | 今义 | 例句 |
|---|---|---|---|
| 间 | 参与 | 中间、隔开 | 又何间焉 |
| 鄙 | 目光短浅 | （品行）恶劣、粗俗 | 肉食者鄙 |
| 牺牲 | 祭祀用的纯色全体牲畜 | 为正义事业献身 | 牺牲玉帛 |
| 狱 | 诉讼事件、案件 | 监狱 | 小大之狱 |
| 虽 | 即使 | 虽然 | 虽不能察 |
| 可以 | 可以凭借 | 能够、行 | 可以一战 |
| 再 | 第二次 | 又一次、重复 | 再而衰 |
| 情 | 实情（一说「诚心」） | 感情 | 必以情 |
| 忠 | 尽力做好分内的事 | 忠诚 | 忠之属也 |
| 属 | 类 | 家属、归属 | 忠之属也 |
| 安 | 安身 | 安全、安稳 | 衣食所安 |
| 加 | 虚夸、夸大（以少报多） | 增加 | 弗敢加也 |
| 信 | 实情 | 诚信、书信 | 必以信 |

「牺牲」可以再拆一层记：色纯叫「牺」，体全叫「牲」，合起来指祭祀用的整只纯色牲畜——所以它跟「献出生命」一点关系都没有。

### 3.3 一词多义

| 词 | 例句与意思 |
|---|---|
| 故 | 公问其**故**（原因）／**故**克之、**故**逐之（所以） |
| 信 | 必以**信**（实情）／小**信**未孚（信用） |
| 以 | 何**以**战（凭、靠）／必**以**分人（把）／必**以**情（根据、按照）／可**以**一战（凭借） |
| 之 | 肉食者谋**之**（代词，指迎战齐军这件事）／公与**之**乘（代词，他，指曹刿）／小大**之**狱（的）／公将鼓**之**（音节助词，不译）／登轼而望**之**、故克**之**、故逐**之**（代词，指齐军）／忠**之**属也（代词，这） |
| 其 | **其**乡人曰（他的，指曹刿）／公问**其**故（其中的，指取胜的）／下视**其**辙、吾视**其**辙乱（他们的，指齐军） |
| 从 | 民弗**从**也（听从、顺从）／战则请**从**（跟随） |
| 属 | 忠之**属**也（类）／**属**予作文以记之（同「嘱」，嘱托）／有良田美池桑竹之**属**（类） |
| 伐 | 齐师**伐**我（攻打）／**伐**竹取道（砍伐） |
| 焉 | 又何间**焉**（语气词，呢）／惧有伏**焉**（兼词，于此、在那里） |

### 3.4 词类活用

- 神弗**福**也：福，名词作动词，赐福、保佑。
- 公将**鼓**之 / 一**鼓**作气：鼓，名词作动词，击鼓进军。
- **下**视其辙：下，名词作动词，下车。

## 四、特殊句式与翻译得分点

| 句式 | 例句 | 还原 / 标志 |
|---|---|---|
| 宾语前置 | 何以战 | ＝以何战，疑问代词「何」作介词「以」的宾语前置 |
| 状语后置 | 战于长勺 | ＝于长勺战，「于长勺」放到动词后 |
| 判断句 | 夫战，勇气也 / 忠之属也 | 「……也」表判断 |
| 省略句 | 必以（之）分人 / 可以（之）一战 | 省宾语「之」 |
| 省略句 | 再（鼓）而（气）衰，三（鼓）而（气）竭 | 省动词「鼓」、主语「气」 |

翻译时把省略的成分补出来、把倒装的顺序顺回来，句子才通；但**加粗的采分字词一个都不能丢**：

1. 何以战？——（您）凭借什么作战？（采分：宾语前置还原、以＝凭。）
2. 衣食所安，弗敢专也，必以分人。——衣食这类安身的东西，不敢独自享有，一定把（它）分给别人。（采分：安＝安身、专＝独自享有、补「之」。）
3. 小大之狱，虽不能察，必以情。——大大小小的诉讼事件，即使不能件件明察，也一定根据实情处理。（采分：狱＝案件、虽＝即使、察＝明察、情＝实情。）
4. 小信未孚，神弗福也。——（这只是）小信用，未能使神灵信服，神是不会保佑您的。（采分：孚＝使信服、福＝保佑。）
5. 忠之属也。可以一战。——（这）是尽了职分一类的事情，可以凭借（这个条件）打一仗。（采分：忠＝尽力做好分内的事、属＝类、可以＝可以凭借。）
6. 一鼓作气，再而衰，三而竭。——第一次击鼓能振作士气，第二次击鼓士气就衰减，第三次击鼓士气就耗尽。（采分：一/再/三＝第一/二/三次、作＝振作、补省略。）
7. 夫大国，难测也，惧有伏焉。——齐是大国，难以推测它的实情，怕在那里有埋伏。（采分：夫不译、测＝推测、焉＝在那里。）

## 五、内容讲透

### 5.1 三问三答：为什么前两条被否、第三条才行

曹刿只问了一句「何以战」，庄公答了三次，曹刿否了两次、肯定一次：

| 庄公的回答 | 曹刿的评判 | 毛病在哪 |
|---|---|---|
| 衣食所安，弗敢专也，必以分人 | 小惠未徧，民弗从也 | 恩惠只分给身边近臣，没遍及百姓，百姓不跟你 |
| 牺牲玉帛，弗敢加也，必以信 | 小信未孚，神弗福也 | 对神诚实只是小信用，没使神信服，神不保佑 |
| 小大之狱，虽不能察，必以情 | 忠之属也。可以一战 | 肯定：办案凭实情，是尽了职分、对百姓负责 |

前两条的共同毛病：**把战争的希望押在少数近臣和神灵身上，唯独没落到百姓身上**。第三条才落到百姓：官司打得公不公，老百姓天天看得见、感受得到，这才是真正赢得民心。所以「可以一战」的条件，用原文说是「小大之狱，虽不能察，必以情」，用自己的话说就是**政治上取信于民**。

这里有两个最容易译错的词。「忠之属也」的「忠」不是「忠诚」，是「尽力做好分内的事」；「属」是「类」，「之」是「这」——整句是「（这）是尽了职分一类的事情」。「必以情」的「情」课本注为「实情」，也有一说解作「诚心」，考试按孩子课本注释答。

追问一句：庄公对神「必以信」，难道不诚实吗？诚实是诚实，但曹刿看的不是「你诚不诚实」，而是「这份诚实能不能换来保佑」——小信未孚，神都不信服，何况百姓？曹刿的思路始终是：**打仗靠人，不靠神，也不靠几个近臣**。

### 5.2 战中两个「未可」、两个「可矣」：战机怎么抓

![士气对比与反攻时机示意图](../images/2026-11/20261115-01.png)

第一次「未可」拦的是「公将鼓之」。看图就懂：齐军一鼓时士气正冲到顶，这时候对鼓等于拿自己的头一次鼓去碰人家的头一次鼓，谁也不占便宜。曹刿让鲁军按住不鼓，**士气一点不消耗**；齐军一鼓、再鼓、三鼓，士气一路掉到底。等到「齐人三鼓」之后，齐竭我盈，鲁军才第一次击鼓——这就是「一鼓作气，再而衰，三而竭。彼竭我盈，故克之」，也是成语「一鼓作气」的出处。跟《孙子兵法》「以逸待劳」是一个道理：让对方先消耗，自己攒着劲。

第二次「未可」拦的是「公将驰之」，这次拦的理由不一样：齐军虽然败了，但齐是大国，**怕它是假装败、引你进埋伏**（夫大国，难测也，惧有伏焉）。所以曹刿不凭感觉下命令，而是实地取两个证据：

![战车辙轼与追击判据示意图](../images/2026-11/20261115-02.png)

- **下视其辙**：下车看齐军车轮碾出的痕迹。车辙乱，说明车队是真的乱了套，不是有序撤退。
- **登轼而望之**：登上车前横木站高了望，看齐军的旗子。旗靡（倒下），说明兵是真的溃散，不是旗号整齐地佯退。

两条证据凑齐，才说第二个「可矣」，于是「遂逐齐师」。

追问一句：只看车辙不行吗？只看旗子不行吗？都不够。车辙乱可能是故意碾乱装败，旗子倒也可能是故意放倒诱敌；**一个看地面、一个看高处，一个看车队、一个看指挥**，两处对上了，「真败」才坐实。这正是曹刿「谨慎、重实证」的地方，也是简答题最爱考的点：答追击依据时「辙乱」「旗靡」两条都要写。

### 5.3 人物：曹刿与鲁庄公（新教材要会辩证评价）

曹刿：

| 特点 | 原文依据 |
|---|---|
| 爱国、有担当 | 国家危难主动「请见」，乡人劝阻也不退：「肉食者鄙，未能远谋」 |
| 政治远见 | 否定近臣与神灵，认定取信于民才是作战前提：「忠之属也。可以一战」 |
| 军事才能、深谋远虑 | 两个「未可」两个「可矣」，把握反攻与追击时机 |
| 从容镇定、重实证 | 齐军败了仍不急着追，「下视其辙，登轼而望之」后才下令 |

鲁庄公要分两面看，只答一面都丢分：

- 「鄙」的一面：战前把希望寄托在近臣拥护和神灵保佑上（目光短浅）；战中「公将鼓之」「公将驰之」两次急躁冒进；战后「公问其故」，赢了还不知道为什么赢。
- 不「鄙」的一面：肯接见平民曹刿并「与之乘」（礼贤下士、任人唯贤）；三问三答都听得进去、战中两次都照曹刿说的办（虚心纳谏、用人不疑）；赢了主动问原因（不耻下问）。

合起来说：庄公政治上目光短浅、军事上急躁无知，但能纳谏、能用人，是个「中等之主」，不是昏君。**没有庄公的放权，曹刿的远谋一句也落不了地**——长勺之赢是两个人合起来的赢。

乡人那句「肉食者谋之，又何间焉」也不是闲笔：用普通百姓的冷漠旁观，反衬曹刿主动担当的可贵。

### 5.4 写法：为什么叫「论战」，不叫「长勺之战」

| 详写 | 略写 / 不写 |
|---|---|
| 战前曹刿与庄公的三问三答 | 战争起因只一句「齐师伐我」 |
| 战中曹刿的四个短句（未可／可矣／未可／可矣）与观察动作 | 战斗场面只「齐师败绩」「遂逐齐师」八个字 |
| 战后曹刿论取胜原因 | 双方兵力、部署、战后封赏一概不写 |

原因一句话：**中心是表现曹刿的政治远见和军事才能，凡与表现人物无关的枝节一律省略**。题目是「论战」，写的就是「论」，不是「战」。

其余三条写法，写记叙文时都能偷师：

- **以对话写人**：全文几乎没有外貌、心理描写，人物全靠自己的话立起来。
- **对比衬托**：乡人的冷漠衬曹刿的担当，庄公的「鄙」衬曹刿的「远谋」。
- **一线串珠**：以「战」为线（迎战—备战—胜战—评战），以曹刿的活动为线（请见—论战—参战—释疑），三段各管一层。

出自本文的成语：一鼓作气、彼竭我盈、辙乱旗靡（也说「再衰三竭」）。

## 七、易错红笔区（过一遍，会的打勾）

**A 字音字形**

- [ ] 刿读 guì，不读 suì；间在「又何间焉」里读 jiàn。
- [ ] 靡在「旗靡」里读 mǐ，不读 mí；夫在「夫战」里读 fú，不读 fū。
- [ ] 乘在「公与之乘」里读 chéng，不读 shèng。
- [ ] 「徧」同「遍」，不写成「偏」「编」；默写字形以课本为准。
- [ ] 辙、轼都是「车」旁；孚上面是「爫」不是「采」。

**B 词义**

- [ ] 「牺牲」古义是祭祀用的牲畜，不是「献身」。
- [ ] 「狱」古义是案件，不是监狱。
- [ ] 「再」是第二次，不是「再一次」；「三」是第三次。
- [ ] 「虽」是即使，不是虽然。
- [ ] 「可以」是「可以凭借」，需要补出宾语「之」。
- [ ] 「忠」是尽力做好分内的事，不是忠诚；「属」是类。
- [ ] 「加」是虚夸、以少报多，不是增加。
- [ ] 「孚」是使信服；「福」是赐福、保佑（名词作动词）。
- [ ] 「鼓」是击鼓进军（名词作动词）；「下视其辙」的「下」是下车。
- [ ] 「故」在「公问其故」里是原因，在「故克之」里是所以。
- [ ] 「焉」在「又何间焉」里是语气词「呢」，在「惧有伏焉」里是「在那里」。

**C 翻译表述**

- [ ] 「何以战」要译成「凭借什么作战」，不能译成「为什么打仗」。
- [ ] 「必以分人」「可以一战」要把省略的「之」补出来译。
- [ ] 「再而衰，三而竭」要补出「击鼓」「士气」，不能译成「再次衰弱、三次枯竭」。
- [ ] 「夫战，勇气也」的「夫」不译，不能译成「丈夫」「那些」。
- [ ] 「战于长勺」要顺成「在长勺作战」。
- [ ] 「小信未孚」主语是「这份小信用」，译成「未能使神灵信服」。

**D 内容理解**

- [ ] 「十年」是鲁庄公十年；「我」指鲁国，不是齐国。
- [ ] 「可以一战」的条件是取信于民（小大之狱，虽不能察，必以情），不是衣食分人、也不是祭祀守信。
- [ ] 反攻时机＝齐人三鼓之后；追击时机＝辙乱旗靡之后。两个时机不能混。
- [ ] 追击依据要写全「辙乱」＋「旗靡」两条，只写一条不完整。
- [ ] 「惧有伏焉」是第二次「未可」的原因，不是第一次「未可」的原因。
- [ ] 第一次「未可」的原因是齐军士气正盛、鲁军尚未击鼓，不是怕埋伏。
- [ ] 鲁庄公不是昏君：能纳谏、能用人、不耻下问；「鄙」只指目光短浅与急躁。
- [ ] 乡人的话是衬托曹刿，不是作者赞成乡人。
- [ ] 详写论战、略写战争，是为了突出曹刿的远谋，不是作者不会写场面。
- [ ] 本文重在「论」，不是重在记叙长勺之战的经过。

**E 文学常识**

- [ ] 选自《左传·庄公十年》；《左传》是编年体史书，旧传为春秋左丘明所作。
- [ ] 《左传》又称《春秋左氏传》《左氏春秋》，是我国第一部叙事详备的编年体史书。
- [ ] 题目「曹刿论战」是教材编者加的，不是原书篇名。
- [ ] 长勺之战是以弱胜强、后发制人的战例；齐强鲁弱。
- [ ] 别混：《战国策》是国别体，《史记》是纪传体通史。

## 九、逐题答案与错因辨析

### 一、判断题

1. √。错因预防：别把「十年」读成「过了十年」。
2. ×。「我」指鲁国。错因：《左传》以鲁国纪年、站在鲁国立场，「伐我」是齐打鲁；看到「我」就代入齐国是最常见的错。
3. ×。读 jiàn，意思是「参与」。错因：用今音今义套古文。
4. ×。指祭祀用的纯色全体牲畜。错因：今义「牺牲」太熟，一读就滑过去。
5. ×。「孚」是「使信服」；「信用」是「信」的意思。错因：把「小信未孚」整个词组的意思安到「孚」一个字上。
6. ×。「再」是第二次。错因：今义「再次」干扰；同理「三」是第三次，不是「多次」。
7. ×。「忠」是尽力做好分内的事。错因：今义「忠诚」干扰；这是全课最隐蔽的一个古今异义。
8. ×。庄公能接见平民、虚心纳谏、用人不疑、不耻下问，不是昏君。错因：只抓「鄙」字一面倒，新教材思辨题这样答必丢分。

### 二、选择题

1. **C**。两个「属」都是「类」。A 原因／所以；B 实情／信用；D 听从／跟随。错因：D 项两个「从」看着都像「跟从」，其实「民弗从」是听从、「请从」是跟随，方向不同。
2. **C**。「伐」的「攻打」与「砍伐」是古汉语里同一个词的两个义项（一词多义），不是古今义变化；A 狱、B 牺牲、D 可以都是古今异义。错因：把一词多义误判成古今异义。
3. **C**。「吾谁与归」＝「吾与谁归」，宾语前置，与「何以战」同。A 状语后置，B、D 判断句。错因：只认「……也」是特殊句式，认不出倒装。
4. **B**。焉＝兼词「于此」，在那里。错因：与「又何间焉」的语气词「焉」混为一谈。
5. **C**。阻止立即追击是怕齐国佯败设伏（夫大国，难测也，惧有伏焉），不是怕士气尚盛；怕士气尚盛是第一次「未可」的原因。错因：两个「未可」的原因张冠李戴，这是内容理解题的第一高频坑。
6. **B**。错因：A、C、D 都是「看起来有点道理」的干扰项；记住详略永远服务于中心与人物。

### 六、简答题

1. 原文：「小大之狱，虽不能察，必以情。」实质：政治上取信于民——办案凭实情、对百姓负责，才能赢得百姓拥护，这才是作战的先决条件。错因：只抄原文不点「取信于民」，或把条件答成「衣食分人」「祭祀守信」。
2. 要两面答。「鄙」：战前寄望近臣与神灵（目光短浅），战中「公将鼓之」「公将驰之」（急躁冒进），战后「公问其故」（不知胜因）。不「鄙」：接见平民并「与之乘」（礼贤下士），三问三答与战中指挥都听曹刿（虚心纳谏、用人不疑），胜后主动问故（不耻下问）。结论：才能平庸但能纳谏用人的中等之主，非昏君。错因：一面倒，或只贴标签不配原文。
3. 中心是表现曹刿的政治远见和军事才能，题目是「论战」；凡与表现人物无关的枝节（战斗场面、兵力部署、战后封赏）一律省略，所以详写言论、略写经过。错因：答成「战争经过不重要」或「作者不会写场面」。
