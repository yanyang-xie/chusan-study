# 涟漪函数（取整函数与二次函数综合）

## 题目

对任意实数 $x$，可用 $[x]$ 表示不超过 $x$ 的最大整数，如 $[1.5]=1$，$[2]=2$，$[-0.6]=-1$。称函数 $y=ax^2+b[x]+c$（$b\neq 0$）为"涟漪函数"。

（1）当 $a=c=0$ 时，若 $y=b$，则 $x$ 的取值范围是 \_\_\_\_\_\_。

（2）当 $a=\dfrac{1}{4}$，$b=-1$，$c=1$ 时，"涟漪函数"与 $x$ 轴共有 \_\_\_\_\_\_ 个公共点。

![题目](../../../images/20260905-01.png)

- 来源：错题本拍照
- 难度：⭐⭐⭐ 超中考（取整函数非人教版初三内容）
- 考查知识点：取整函数（高斯函数）的定义与性质、二次方程求解、不等式约束筛选

## 解题思路

- **核心困难**：方程中同时出现 $x$（连续）和 $[x]$（跳跃），混在一起无法直接解
- **关键策略**：设参数 + 回代约束——给 $[x]$ 起个名字 $n$，先放开约束求解，再用约束回收
- **通用套路**：遇到"不好直接处理"的量 → 设参数 → 先求解 → 再用约束筛选（三角换元、参数方程等也是同一思路）

## 解答过程

### 第（1）问

当 $a=c=0$ 时，函数为 $y=b[x]$。

由 $y=b$，得 $b=b[x]$。

因为 $b\neq 0$，两边除以 $b$，得 $[x]=1$。

根据取整函数定义，$[x]=1$ 表示不超过 $x$ 的最大整数为 $1$，因此 $x$ 的取值范围是 $1\leqslant x < 2$。

**答案**：$1\leqslant x < 2$

---

### 第（2）问（重点）

当 $a=\dfrac{1}{4}$，$b=-1$，$c=1$ 时，函数为 $y=\dfrac{1}{4}x^2-[x]+1$。

> 方程里同时有 $x$（连续）和 $[x]$（跳跃），混在一起无法直接解。怎么办？给 $[x]$ 设个整数参数 $n$，先放开约束求解，最后用约束回收——这是通用套路，三角换元、参数方程等也是同一思路。

**第 1 步：令 $y=0$，建立方程**

$$\frac{1}{4}x^2-[x]+1=0$$

**第 2 步：设 $[x]=n$（$n$ 为整数），代入方程**

$$\frac{1}{4}x^2-n+1=0 \implies x^2=4(n-1)$$

> **为什么只用 $n$ 替换 $[x]$，不用 $n+1$？**
> $n$ 是 $[x]$ 的**值**，所以方程里用 $n$ 替换 $[x]$；$n+1$ 不是 $[x]$ 的值，它只是取整函数定义中的**上界**，只在约束条件 $n\leqslant x < n+1$ 中出现，用来检验 $x$ 是否合法。

**第 3 步：确定 $n$ 的大范围**

因为 $x^2\geqslant 0$，所以 $4(n-1)\geqslant 0$，即 $n\geqslant 1$。

解出 $x$（取非负根，因为 $n\geqslant 1$ 时 $x\geqslant 0$）：

$$x=2\sqrt{n-1}$$

**第 4 步：用约束条件 $n\leqslant x < n+1$ 筛选 $n$**

将 $x=2\sqrt{n-1}$ 代入：

$$n\leqslant 2\sqrt{n-1} < n+1$$

**解左边不等式** $n\leqslant 2\sqrt{n-1}$：

两边平方（$n\geqslant 1$ 时两边均非负）：

$$n^2\leqslant 4(n-1) \implies n^2-4n+4\leqslant 0 \implies (n-2)^2\leqslant 0$$

完全平方 $\leqslant 0$，唯一可能：$n=2$。

**解右边不等式** $2\sqrt{n-1} < n+1$：

两边平方：$4(n-1) < (n+1)^2 \implies 0 < (n-1)^2+4$，对一切整数恒成立，无额外限制。

> **为什么主要解左边、右边只是验证？**
> 两个不等式要同时满足，取交集。左边已经"一锤定音"把 $n$ 唯一确定为 $2$，右边恒成立自动满足，所以不需要再单独求。如果情况反过来（左边恒成立、右边给出唯一解），那就只需求右边——**谁给出了更强的约束，就听谁的**。

取交集：$n=2$。

**第 5 步：求出 $x$ 并验证**

$n=2$ 时：

$$x=2\sqrt{2-1}=2$$

三重验证：

- $[x]=[2]=2=n$ ✓
- 约束 $n\leqslant x < n+1$：$2\leqslant 2 < 3$ ✓
- 代入原函数：$y=\dfrac{1}{4}\times 4-2+1=0$ ✓

**答案**：函数与 $x$ 轴有 **1** 个公共点 $(2,\,0)$。

## 相关知识点

- **取整函数（高斯函数）**：$[x]$ 表示不超过 $x$ 的最大整数，满足 $[x]\leqslant x < [x]+1$
- **完全平方的非负性**：$(n-2)^2\geqslant 0$ 恒成立，等号仅在 $n=2$ 时取到
- **不等式两边平方的前提**：必须确保两边均非负才能平方

## 易错点提醒

- **忘记验证约束**：解出 $x=2\sqrt{n-1}$ 后，必须回代 $n\leqslant x < n+1$ 检验，否则可能得到增解
- **混淆 $n$ 和 $n+1$ 的角色**：$n$ 是 $[x]$ 的值（代入方程），$n+1$ 只是约束的上界（不参与方程）
- **平方时忽略前提条件**：对不等式两边平方前，必须确认两边非负
