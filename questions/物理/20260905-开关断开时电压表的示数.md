# 开关断开时，电压表有没有示数？（判断方法 + 常见错误）

## 题目

电路：一个电源、一个灯泡、一个开关串联。开关接在电源负极一侧，正极通过导线直接接灯泡（见下图）。

问：

1. 开关闭合时，电压表接在灯泡两端，能测出电压吗？
2. 开关断开时，电压表接在灯泡两端，能测出电压吗？
3. 开关断开时，电压表接在开关两端呢？
   正确结论：开关断开、表接灯泡 → 示数为 0

![电路结构](../../images/20260905-1.png)

## 解题思路

- **电压表有示数的本质**：两个接线柱之间存在电势差。操作化判断：看电压表能否跟电源构成**闭合回路**（能 → 有微小电流流过表 → 有读数；不能 → 0）。
- **关键推论（本题的钥匙）**：无电流时，导通的元件（导线、灯泡、电阻）两端没有电压，因为 U = I·R = 0，它们相当于一根导线 → 同一"导通段"上所有点**电势相同**。
- **等电势判断三步法**：
  1. 找电压表接的是哪两个点；
  2. 判断每个点：经"导通段"能连到正极 → 正极电势；能连到负极 → 负极电势；
  3. 两点电势相同 → 0 V；一正一负 → ≈ 电源电压。
- **一句话口诀：开关断开没电流，电压只出现在"断点"上；电压表"跨"住断点才有示数。**

## 直观理解：为什么"没电流 ⇒ 电阻两端电压为 0"？

### 类比一：连通的水渠（最好懂）

把电路想象成一条从**高水塔**流到**低水池**的水渠：

- 水塔 = 电源正极（水位高 = 电势高）
- 水池 = 电源负极（水位低 = 电势低）
- 水渠 = 导线
- 中间一段**窄渠** = 灯泡（水挤过去时水位会掉）
- 中间一道**闸门** = 开关
- 水位差测量仪 = 电压表

**闸门打开**：水流动。窄渠处因为阻力大，水位明显下降（上游高、下游低）——这就是"灯泡两端有电压"。

**闸门关闭**：水**完全静止**。这时初中的**连通器原理**告诉我们：静止的水面必然是平的！

- 从水塔一直到闸门这一整段，水面全都跟水塔一样高（都是"高水位"）；
- 从闸门到水池这一段，水面全都跟水池一样低（都是"低水位"）；
- **只有闸门本身**两侧水位不同（一边高一边低）。

**窄渠两端**呢？都在闸门上游，水面一样高，**没有落差**。所以水位差测量仪接在窄渠两端读数为 0，接在闸门两端读数最大。

这就是本题的物理图景。

### 类比二：欧姆定律严格证明

水渠只是帮助直觉。严格来讲，一步就够：

> **U = I · R**

- 开关断开 → 串联电路处处 I = 0；
- 灯泡两端电压 U_灯 = I · R_灯 = 0 × R_灯 = **0**；
- **跟灯泡电阻多大无关**，电阻再大，0 × R 还是 0。

核心一句话：**一个电阻两端要有电压，必须有电流流过它**。没电流，就没电压。

### 那为什么断点（开关）两端反而有电压？

因为断点**不是电阻**，它是"没有通路"。判断逻辑完全反过来：

- 电压表接到断点两端时，**电压表自己**成了唯一通路；
- 电压表内阻极大（一般几兆欧），但**不是无穷大**，还是有极微弱电流通过；
- 这个微弱电流构成新回路：正极 → 灯泡 → 电压表 → 负极；
- 串联分压：R_V ≫ R_灯，几乎全部电压降在电压表上 → 读数 ≈ 电源电压。

**关键区别**：

| 元件 | 有电压的条件 |
|------|--------------|
| 电阻（灯泡、变阻器） | 需要**外部电流**流过它 |
| 断点（开关断开处、灯丝烧断处） | 电压表接上去时**自己造出**微弱电流 | 

前者没电流就没电压，后者电压表"救活"了回路。

## 万能三步判断法（记这一个就够）

遇到任何"电压表读数"题，按这三步走，永远不会错：

**第 1 步：找断点** —— 电路"断"在哪里？
- 开关断开处
- 灯丝烧断处
- 导线接头松脱处
- 电路完好闭合无断点？那就直接用欧姆定律算

**第 2 步：分两侧** —— 用断点把电路切成两段：
- 从**正极**出发沿导线走，能走到的所有点 = **正极电势**（无电流通过任何元件，一路不降压）
- 从**负极**出发同样操作，能走到的所有点 = **负极电势**
- 走不通的地方就是断点

**第 3 步：看表接哪** ——
- 两接线柱**同侧** → 示数 = **0**
- 两接线柱**异侧**（跨住断点）→ 示数 ≈ **电源电压**

**用文字示意图理解**（本题的情况②）：

```
开关断开时：

  正极 ──●A── [灯泡] ──●B──●C── [开关断] ──●D── 负极
        ═════════════════════════         ═══════════
         上游段：全是正极电势              下游段：全是负极电势
         （无电流，电势处处不变）          （无电流，电势处处不变）

  表接 A、B：同在上游 → 0 V          ← 本题情况②
  表接 B、C：同在上游 → 0 V
  表接 C、D：跨住断点 → ≈ 电源电压    ← 本题情况③
  表接 A、D：跨住断点 → ≈ 电源电压
```

## 解答过程

电路标号：正极 — A — 灯泡 — B — C — 开关 — D — 负极（见上方电路图）。

### 情况①：开关闭合，电压表接灯泡两端（A、B）

1. 回路完整 → 有电流，灯亮；
2. A 连正极一侧（高电势）；B 经闭合开关（相当于导线）连负极一侧（低电势）；
3. U_AB ≈ 电源电压（理想情况下等于电源电压）。

**结论：有示数 ≈ 电源电压。**

![情况1：开关闭合，表接灯泡](../../images/20260905-2.png)

### 情况②：开关断开，电压表接灯泡两端（A、B）★ 最容易错

1. 开关断开 → 主电路断 → **整个电路没有电流**（I = 0），灯不亮；
2. 灯泡上没有电流：U = I·R = 0 × R = 0 → **灯泡两端没有电势差**，灯泡此刻相当于一根导线；
3. 所以从正极出发，经导线、灯泡一直到 C 点，**全部处于"正极电势"**（图中蓝色区域）；D 点到负极全部处于"负极电势"（红色区域）；
4. A、B 同属"正极电势"段 → 电势差 = 0 → **电压表示数为 0，指针不偏转**。

回路角度再验证：电压表要有读数，必须有（微小）电流流过它，即它要与电源构成回路。可 A、B 两点出去的路，在开关处断了 → 回路构不成 → 无电流 → 读数为 0。

**结论：示数 = 0。**（GPT 的解答错在这里，说成"≈ 电源电压"，千万别背反！）

![情况2：开关断开，表接灯泡](../../images/20260905-3.png)

### 情况③：开关断开，电压表接开关两端（C、D）

1. C 在正极一侧 → 正极电势；D 在负极一侧 → 负极电势；
2. 电压表内阻极大（可看作一个"超级大电阻"），此时它**唯一"桥"住了断点**，与电源构成回路：正极 → 灯泡 → 电压表 → 负极；
3. 电流 I = U / (R灯 + R_V)。因为 R_V ≫ R灯，I 极小（所以灯不亮），但**电压几乎全降在电压表上**：U_V = U · R_V / (R灯 + R_V) ≈ U。

**结论：有示数 ≈ 电源电压。**

![情况3：开关断开，表接开关](../../images/20260905-4.png)

### 对比总结


| 电压表接在 | 开关闭合                    | 开关断开                     |
| ---------- | --------------------------- | ---------------------------- |
| 灯泡两端   | 有示数 ≈ 电源电压（灯亮）  | **示数 = 0**（灯不亮）       |
| 开关两端   | 示数 = 0（闭合开关 = 导线） | 有示数 ≈ 电源电压（灯不亮） |

**口诀：开关断开没电流，电压只出现在断点。电压表"跨"住断点才有示数。**

## 更多例题（变式训练，掌握三步法）

下面五道题都用"三步判断法"，自己先盖住答案试试。

### 例题 1：两个灯泡串联 + 开关断开

电路：正极 → L1 → L2 → 开关（断开）→ 负极。

标号：正极 — A — L1 — B — L2 — C — 开关 — D — 负极。

问：电压表分别接下列两点，示数各是多少？

| 接法 | 位置 | 示数 | 原因 |
|------|------|------|------|
| (a) A、B | L1 两端 | **0** | 同在上游段（正极电势） |
| (b) B、C | L2 两端 | **0** | 同在上游段（正极电势） |
| (c) A、C | L1+L2 两端 | **0** | 同在上游段（**跨了两个灯泡也没用**） |
| (d) C、D | 开关两端 | **≈ 电源电压** | 跨住了断点 |
| (e) A、D | 整个电路两端 | **≈ 电源电压** | 跨住了断点 |

**关键提醒**：(c) 特别容易错。有同学会想"跨了两个灯泡，总应该有点电压吧"——**错**！电压表读数只看两接线柱的**电势差**，不看中间"包"了多少元件。中间没电流，就没电势差。

### 例题 2：灯泡烧断（灯丝断了），开关闭合

电路：正极 → 开关（闭合）→ 灯泡（灯丝烧断）→ 负极。

标号：正极 — A — 开关 — B — 灯泡 — C — 负极。

**分析**：断点从"开关处"转移到了"灯泡处"！
- 上游段：正极 — A — 开关（闭合=导线）— B → 全是正极电势
- 下游段：C — 负极 → 全是负极电势

| 接法 | 示数 | 原因 |
|------|------|------|
| A、B（开关两端） | **0** | 同在上游段 |
| B、C（灯泡两端） | **≈ 电源电压** | 跨住了断点（断点在灯泡） |
| A、C（开关+灯泡） | **≈ 电源电压** | 跨住了断点 |

**重要对比**（把本题和例题 2 放一起看）：

| 电路状况 | 表接灯泡两端 | 原因 |
|----------|--------------|------|
| 开关断开、灯泡完好（本题情况②） | **0** | 断点在开关，灯泡处不是断点 |
| 开关闭合、灯泡烧断（例题 2） | **≈ 电源电压** | 断点在灯泡，表刚好跨住断点 |

**只差"断点在哪"**，结论完全相反！所以**永远先找断点**，再看表接哪里。

### 例题 3：并联电路，一条支路断开

电路：电源 → 干路开关 S1（闭合）→ 分支点 P → 
- 支路1：灯 L1 → 开关 S2（断开）→ 汇合点 Q
- 支路2：灯 L2 → 汇合点 Q

→ Q → 电源负极。

**分析**：
- S1 闭合、L2 支路完整 → 干路和 L2 有电流，L2 正常发光
- L1 支路断在 S2 → **L1 支路无电流**
- P 点 = 正极电势（通过闭合的 S1 直连正极）
- Q 点 = 负极电势（直连负极）

L1 支路内部：P → L1 → 中间点 M → S2 → Q
- L1 无电流 → L1 两端（P、M）电势相同 = 正极电势
- S2 是断点 → S2 两端（M、Q）：M = 正极电势、Q = 负极电势

| 接法 | 示数 |
|------|------|
| L1 两端（P、M） | **0** |
| S2 两端（M、Q） | **≈ 电源电压** |
| L1+S2 两端（P、Q） | **≈ 电源电压** |
| L2 两端 | **≈ 电源电压**（L2 正常工作） |

**启示**：并联电路中，**某一支路断开只影响这一支路**。其他支路仍然正常工作。但断开支路里的灯泡两端仍然是 0 V（因为无电流）。

### 例题 4：滑动变阻器 + 开关断开

电路：正极 → 灯泡 → 滑动变阻器（阻值调到最大，如 1000 Ω）→ 开关（断开）→ 负极。

**分析**：开关断开 → 全电路无电流。**变阻器阻值再大也没意义**，因为 U = I·R = 0 × R = 0。

| 接法 | 示数 |
|------|------|
| 灯泡两端 | **0** |
| 变阻器两端 | **0**（哪怕阻值 1000 Ω、10000 Ω，都是 0） |
| 灯泡+变阻器两端 | **0** |
| 开关两端 | **≈ 电源电压** |

**陷阱提醒**：很多同学看到"变阻器阻值大"就想当然认为"两端电压大"。**错**！电压大小只由 I × R 决定，I = 0 时，R 再大也是 0。

### 例题 5：电压表只接一根线（悬空）

电压表一端接在电路某点，另一端**悬空**（什么都没接）。

**答**：示数 = **0**。

**原因**：构不成回路，电压表内部没电流，指针不偏转。

**引申**：电压表要有读数，必须同时满足两个条件：
1. **两个接线柱都接到电路上**（缺一不可）
2. 两点之间有**电势差**（跨住断点）

少任何一个都不行。

## 相关知识点

- **欧姆定律 U = I·R**：没有电流流过的电阻（灯泡），两端电压为 0；
- **串联电路**：断开任意一处，整个电路就没有电流；
- **电压表内阻极大**：一般可视为断路；但当电路有断点、电压表恰好是唯一的通路时，那一点微小电流就构成回路，且因 R_V 最大，几乎全部电压降在电压表上；
- **等电势点判断法**：无电流时，导通段（导线、用电器）上各点电势相同——这是判断电压表读数的核心工具。

## 易错点提醒

1. **开关断开 + 表接灯泡 = 示数 0**，不是"≈ 电源电压"。GPT 的解答就错在这里：它认为"灯泡一端接正极，所以有电压"，漏掉了"没有电流流过灯泡时，灯泡不降压，另一端同样是正极电势"。
2. 和下面这题**只差断点位置**，最容易混，务必对比记忆：


   | 电路状况                       | 电压表接灯泡两端 | 原因                         |
   | ------------------------------ | ---------------- | ---------------------------- |
   | 开关断开（灯泡完好）           | **0**            | 断点在开关，灯泡无电流不降压 |
   | 灯泡断路（灯丝烧断，开关闭合） | **≈ 电源电压**  | 断点在灯泡，电压表桥住了断点 |
3. **"没有电流 ≠ 没有电压"要分清用在哪**：断开的开关本身没有电流，但两端有电压（≈ 电源电压），因为它就是断点；而"没有电流流过**某个电阻**"⇒ 该电阻两端电压必为 0（U = I·R）。判断的关键永远是同一句话：**电压表接在哪两个点，这两个点电势同不同。**

## 追问记录

- **Q（20260905）：为什么开关断开时，电压表接在灯泡两端示数为 0？我还是理解不了。**

  A：核心是把"电压 = 电势差"和"没电流 ⇒ 电阻不降压"两件事真正想通。三个角度一起看：

  1. **连通器类比**：把电路想成一条从高水塔到低水池的水渠，灯泡是窄渠、开关是闸门。闸门关闭时水完全静止，根据**连通器原理**，静止水面必然是平的——从水塔到闸门的水面全都一样高，窄渠两端水面也一样高，没有落差。**只有闸门本身**两侧水位不同。电压表接窄渠两端 = 0；接闸门两端 = 电源电压。

  2. **欧姆定律**：U = I · R。开关断开 → 串联电路处处 I = 0 → 灯泡两端 U = 0 × R = 0。跟灯泡电阻多大无关。

  3. **等电势判断**：从正极出发沿导线、灯泡一路走过去，因为无电流，电势处处不变，全都是"正极电势"。灯泡两端 A、B 同属正极电势段 → U_AB = 0。

  **记住万能三步法：找断点 → 分两侧 → 看表接哪（同侧 0，异侧电源电压）**。上面"更多例题"五道变式题反复练习这个三步法。
