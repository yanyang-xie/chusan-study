> 本讲主线：测电阻的本质永远是 $R = U / I$ ——想办法知道待测电阻两端电压 $U_x$ 和通过它的电流 $I_x$。缺电压表就想办法"造"出电压，缺电流表就想办法"造"出电流。

## 考点一 安阻法测电阻（只有电流表 + 已知阻值 $R_0$）

**思路**：缺电压表，想方法测电压。

1. 在 $R_x$ 两端**并联**一个已知阻值的电阻 $R_0$；
2. 用电流表测出通过 $R_0$ 的电流 $I_0$；
3. 由 $U_x = U_0 = I_0 R_0$ 算出待测电阻两端电压（并联支路电压相等）。

再测（或算出）通过 $R_x$ 的电流 $I_x$，则 $R_x = U_x / I_x = I_0 R_0 / I_x$。

## 考点二 伏阻法测电阻（只有电压表 + 已知阻值 $R_0$）

**思路**：缺电流表，想方法测电流。

1. 把 $R_x$ **串联**一个已知阻值的电阻 $R_0$；
2. 用电压表测出 $R_0$ 两端电压 $U_0$；
3. 由 $I_x = I_0 = U_0 / R_0$ 算出待测电阻的电流（串联电流处处相等）。

再测 $R_x$ 两端电压 $U_x$，则 $R_x = U_x R_0 / U_0$。

### 例 2（讲义第 2 页）

用 $R_0$ 和一块电压表测 $R_x$。操作：① 闭合 $S_1$、 $S_2$，电压表示数 $U_1$；② 只闭合 $S_1$，电压表示数 $U_2$。选导线接法及表达式。

**分析**：两次开关状态对应"电压表测电源总电压"和"电压表测某个电阻的分压"。若 $S_2$ 闭合时 $R_x$ 被短路、电压表测电源电压 $U_1$， $S_2$ 断开时 $R_0$ 与 $R_x$ 串联、电压表测 $R_x$ 电压 $U_2$，则 $R_0$ 分压 $U_1 - U_2$，电流 $I = (U_1 - U_2) / R_0$，得

$$R_x = \frac{U_2 R_0}{U_1 - U_2}$$

对照选项：导线接法必须让电压表在两种开关状态下分别落在"总电压"和" $R_x$ 电压"两个位置，选出表达式为 $R_x = U_2 R_0 / (U_1 - U_2)$ 的那一项（具体接法 ac/bc/ad/bd 需对照讲义第 2 页原图确认）。

### 考点三 借助滑动变阻器测未知电阻（讲义第 3 页）

**电压表已知（串联分压型）**：将滑动变阻器与 $R_x$ 串联，电压表测 $R_x$ 两端电压。分别测滑片在**阻值最大处**（设最大阻值 $R$）和**阻值为零处**时的电压 $U_1$、 $U_2$：

- 滑片在零处：变阻器不分压，电压表读数即电源电压 $U = U_2$；
- 滑片在最大处： $R$ 与 $R_x$ 串联分压，变阻器分压 $U_2 - U_1$，电流 $I = (U_2 - U_1) / R$，

$$R_x = \frac{U_1 R}{U_2 - U_1}$$

**电流表已知（并联分流型）**：将滑动变阻器与 $R_x$ 并联，电流表在干路。分别测变阻器阻值最大和为零时的干路总电流，利用并联电压相等列方程求解。

**核心要点**：两种方法都是**用滑动变阻器制造两种极端电路状态**，结合欧姆定律求解。前提是**必须知道滑动变阻器的最大阻值**。

- 丙图（电压表）：滑片在 a 端记下 $U_a$，在 b 端记下 $U_b$。一端使变阻器接入为零（电压表读数为电源电压），另一端全接入串联分压：

$$R_{灯1} = \frac{U_b   R_{滑}}{U_a - U_b}$$

- 丁图（电流表）：滑片在 a 端记 $I_a$、b 端记 $I_b$。一端只有灯泡接入（ $U = I_a R_{灯}$ ），另一端灯泡与最大阻值 $R_{滑}$ 并联、电流表在干路。利用电源电压不变，两支路电压相等： $(I_b - I_a) R_{滑} = I_a R_{灯}$ ，整理得讲义标准结果为

$$R_{灯2} = \frac{(I_b - I_a) R_{滑}}{I_a}$$

（以丁图实际连接为准： $I_a$ 是只有灯泡时的电流， $I_b$ 是灯泡与最大 $R_{滑}$ 并联后的干路电流，变阻器支路电流 $I_b - I_a$，两支路电压相等： $(I_b - I_a) R_{滑} = I_a R_{灯}$。）

$$R_x = \frac{I_1 R_1 - I_2 R_1 / 2}{I_2 - I_1} = \frac{(2 I_1 - I_2) R_1}{2 (I_2 - I_1)}$$

## 考点四 等效替代法测电阻（电阻箱）

**原理**：让待测电阻 $R_x$ 和电阻箱 $R_0$ 分别接入**同一位置的电路**，保持其他条件不变，若电表示数相同，说明两者"效果相同"，则 $R_x$ 等于电阻箱读数。

关键：**替换前后电路其余部分一律不动**（滑片位置不变、电源不变），只改变"接入的是 $R_x$ 还是电阻箱"。

![例4与变式4-1](../images/2026-10/20261004-06.png)

**分析**： $R_x \approx 500\Omega$、 $U \approx 3V$ 时电流约 $3 / 500 = 0.006A$，电流表 0~0.6A 量程分度值 0.02A，**根本读不出**，伏安法误差极大。只有等效替代法（电阻箱读数、不依赖小电流读数）能准确测出。选含电阻箱等效替代的电路（C 或 D，按讲义图判定）。

**第 6 题**：甲图（电压表 + 定值电阻 $R$）：常见接法是只闭合 $S$ 时 $R$ 与 $R_x$ 串联、电压表测 $R_x$ 电压 $U_1$； $S$、 $S_1$ 都闭合时 $R$ 被短路，电压表测电源电压 $U_2$。则只闭合 $S$ 时 $R$ 分压 $U_2 - U_1$，电流 $I = (U_2 - U_1) / R$，得 $R_x = U_1 R / (U_2 - U_1)$。
乙图（电流表 + $R$）：只闭合 $S$ 时电流表读数 $I_1$，都闭合时读数 $I_2$。若 $S_1$ 控制 $R$ 支路的通断且电流表在干路，则 $R$ 支路电流 $I_2 - I_1$，电源电压 $U = (I_2 - I_1) R$，故 $R_x = U / I_1 = (I_2 - I_1) R / I_1$。
两式分别与选项对照，选出匹配的项（注意：具体哪个表测哪段以讲义第 10 页原图为准，先判断开关两种状态下表的测量对象再套式）。

## 相关知识点汇总

- 欧姆定律： $I = U / R$，变形 $R = U / I$（测电阻的理论依据）
- 串联：电流处处相等，电压按电阻正比分配（分压公式）
- 并联：各支路电压相等，电流按电阻反比分配（分流公式）
- 电阻箱：能直接读出阻值的可变电阻；滑动变阻器：只能改变阻值、读不出数值（除非已知最大值）
- 等效替代思想：效果相同（电表示数相同）→ 阻值相同，是"特殊方法"里最精确的一种
- 实验安全规范：连接电路时断开开关；闭合前滑片放阻值最大处（保护电路）
- 灯丝电阻随温度升高而增大 → 测灯泡电阻**不能**求平均值

## 易错点提醒

- 安阻法要**并联** $R_0$（借它算电压），伏阻法要**串联** $R_0$（借它算电流），别记反
- 等效替代法替换后**滑片绝对不能再动**，动了"等效"就不成立
- 借助滑动变阻器的两种极端状态法，**必须知道变阻器最大阻值**，否则方程解不出
- 判断"能不能测出"：数一数两种状态给出的独立方程个数，未知量（电源电压、 $R_x$）不超过方程个数才能测出；两状态实质是同一方程的测不出
- 电流太小时（如 500Ω、3V → 6mA）电流表读不出，伏安法失效，必须换等效替代
- 开关断开导致电压表串联进电路时，电压表读数≈电源电压，不是故障误判的理由而是断路的证据
- 内接外接误差口诀："大内偏大、小外偏小"
